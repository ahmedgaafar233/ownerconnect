# دليل تشغيل مشروع OwnerConnect

## المتطلبات المسبقة (Prerequisites)
هذا المشروع يحتاج إلى **Python** ليعمل.
للأسف، لم يتم العثور على Python مثبتًا على جهازك.

### 1. تثبيت Python
1. قم بتحميل Python من الموقع الرسمي: https://www.python.org/downloads/
2. **هام جدًا**: أثناء التثبيت، تأكد من وضع علامة (Check) على خيار:
   **"Add Python to PATH"**
3. بعد التثبيت، أعد تشغيل الجهاز أو سطر الأوامر.

## تشغيل المشروع
لقد قمت بإنشاء ملف تشغيل تلقائي لتسهيل الأمر عليك.

1. بعد تثبيت Python، اذهب لمجلد المشروع.
2. اضغط مرتين على ملف **`start_server.bat`**.
3. سيقوم الملف بـ:
   - إنشاء بيئة افتراضية جديدة.
   - تثبيت المكتبات اللازمة.
   - تجهيز قاعدة البيانات.
   - تشغيل السيرفر وفتح الموقع تلقائيًا.

## لوحة التحكم
- الرابط: http://127.0.0.1:8000/admin/
- توثيق الـ API: http://127.0.0.1:8000/api/schema/swagger-ui/

## المساعدة
إذا واجهت أي مشكلة، تأكد من أن الأمر `python --version` يعمل في سطر الأوامر (CMD).
